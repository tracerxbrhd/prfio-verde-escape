Project notes

Verde Escape is a fictional hospitality concept built as a frontend exercise around a small, explicit stay-planning model.

Imagery

The two cabin images were created specifically for this project and are stored locally as forest-cabin.webp and oak-interior.webp. The cabins are imagined places rather than real properties or commercial listings.

Interface assets

The leaf mark, arrows and remaining interface graphics are local project assets. Typography uses system fonts and the site does not fetch external fonts, stock photography or third-party icon packs at runtime.

Planner boundary

The stay planner calculates dates, capacity, pet eligibility and indicative price in the browser. It does not query live availability, accept payment, persist reservations or send booking requests.

Implementation

HTML, CSS, vanilla JavaScript and Vite. Date and pricing rules live in src/booking.js; page interaction is coordinated by src/main.js.
